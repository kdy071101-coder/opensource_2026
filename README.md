# 오픈소스기초설계 프로젝트

## 프로젝트 주제
**리눅스 비정상 로그인 탐지 및 보안 모니터링 시스템**

## 프로젝트 소개
Ubuntu SSH 인증 로그를 Python으로 분석하여 비정상적인 로그인 시도를 탐지하는 프로그램입니다.

## 주요 기능
- SSH 로그인 실패 기록 분석
- 반복 로그인 실패 탐지
- 탐지 결과 시각화

## 개발 환경
* Python
* Ubuntu Linux
* Streamlit
